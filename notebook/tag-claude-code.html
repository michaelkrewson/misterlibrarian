TECHNOLOGY · SEPTEMBER 11, 2026 My Collaborator Has No Memory Except the Notes I Keep for It For three months I have worked every day with an AI coding assistant that wakes up each session knowing nothing about the last one. What it knows, it reads from a file. That file grew to 685 kilobytes, went stale in ways that reached the real-money side of the project, and turned into the best lesson in institutional memory I have had. This is what it is like to run a one-person shop with an amnesiac partner, and why the answer turned out to be less writing, not more.
